# Proof references

## Device recordings

- Recorded on 27 October 2026 using the connected Samsung Galaxy Note 10+, model SM-N975F.
- Both clips were captured from the installed Motion Lab Android app using Android screen recording.
- Financial proof: the financial accounts page, with the hand style and page switcher hidden.
- Kitty 1 proof: the concept cards page, with the paw style and switcher hidden.
- The input was a downward swipe from (480, 420) to (480, 1550) over 900 ms on the device display.
- Public clips are cropped to remove system status and navigation bars, encoded as H.264, and contain no audio. Animation playback speed was not changed.
- Still images are extracted from those recordings.
- Sampled frames were visually reviewed for entry, search, grip and return to rest. No performance benchmark, accessibility assessment or full device compatibility review is claimed.
